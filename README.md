# BlazorDbzPersonagem

Aplicação Blazor WebAssembly para consultar personagens do Dragon Ball usando a API pública do Dragon Ball API.

## Funcionalidades

- Busca um personagem pelo ID
- Exibe nome
- Exibe planeta de origem
- Exibe transformações
- Mostra imagem do personagem

## Como executar

1. Abra o projeto no VS Code ou no Visual Studio.
2. Execute o comando:

```bash
dotnet run
```

3. Acesse a aplicação no navegador em:

```text
http://localhost:5000
```

ou em outra porta indicada pelo terminal.

## Tecnologias

- .NET 10
- Blazor WebAssembly
- C#

## API utilizada

- https://dragonball-api.com/api/characters/{id}
